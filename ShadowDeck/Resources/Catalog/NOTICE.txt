ShadowDeck Catalog Data
=======================

## SR5 (`sr5_catalog.json`)

Derived from the Chummer5a project data XML files:

  https://github.com/chummer5a/chummer5a

Those source data files are free software under the GNU General Public License
v3 (or later), as stated in the Chummer5a repository (`LICENSE`, `xml_license.txt`).

This catalog is provided for use with ShadowDeck under the same GPL-3.0 terms
as they apply to the redistributed data portion.

No Chummer installation is required to use ShadowDeck. Catalog regeneration,
if performed by maintainers, uses local tooling outside this public repository.

## SR4A (`sr4_catalog.json`)

Mechanical tables (item names, nuyen costs, availability, Essence, chargen BP
rules for spells/contacts/skills, quality BP costs) extracted for companion use
from the **Shadowrun 20th Anniversary Core Rulebook** (SR4A) plus SR4
supplement gear/ware tables (e.g. Arsenal, Augmentation, Street Magic,
Runner’s Companion, Unwired, War, Spy Games, Gun Heaven, and related books).

Maintainer regeneration (local):

  python3 Scripts/build_sr4_catalog_from_books.py

Book PDFs are expected under `~/Desktop/books/` (not shipped). Entries are
deduplicated by **kind + name** (core `source=SR4A` wins on collisions).

**Edition note:** This is **SR4A** (20th Anniversary Edition, 2009), fully
compatible with Shadowrun Fourth Edition books. It is **not** a separate product
line called “SR4E.” Community “4e” slang usually means fourth edition in general;
ShadowDeck’s SR4 profile targets **SR4A**.

Full rule text and fiction are **not** redistributed. Game content remains the
property of its respective trademark and copyright holders. ShadowDeck is an
unofficial fan tool and is not affiliated with Catalyst Game Labs or WizKids.

Known table values (e.g. Ares Predator IV ¥350, Armor Vest ¥600, Datajack
¥500 / 0.1 ESS) are validated by automated spot-checks in unit tests / catalog
manifests where present.

## SR6 (`sr6_catalog.json`)

Mechanical tables extracted from the **Shadowrun Sixth World Core Rulebook
(City Edition Seattle)** gear listing (names, nuyen, availability, essence,
damage — not full rule text).

Known table values (e.g. Combat Axe ¥500, Ares Predator VI ¥750, Datajack
¥1,000 / ESS 0.1, Armor Jacket ¥1,000) are validated by automated spot-checks.

Full rule text is not redistributed. Game content remains property of its
rights holders. ShadowDeck is unofficial and unaffiliated with Catalyst Game Labs.
